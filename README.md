Based on the decompilation project by testyourmine.

Project with ambition of adding the following hollow knight inspired changes:
- Directional dash that's also usable mid-air
- Integrating the Flying Armour Levitation soul in base movement after its unlocked, and removing MP cost (I'm thinking it activates after the apex of the jump when the player is holding Jump or when mid-air without any jumps remaining)
- Smoother slide? Its already integrated in base movement when unlocked
- Smoother aerial control?
- Pogo? Kicker Skeleton soul could be used for this but might be too easy, i need to test how it currently works
- See if I can make the movement feel crispier. Stronger gravity maybe? Change how momentum works?
- Quick Parry soul from Dead Warrior could be integrated into base kit
- Maybe adjust some souls to make them more awesome? Check if AoS supports more souls = more strength, if not maybe integrate it
