# Castlevania: Aria of Hollow

Based on the decompilation project by testyourmine.

Project with ambition of adding the following hollow knight inspired changes:
- Directional dash that's also usable mid-air
- Integrating the float skill in base movement after its unlocked (I'm thinking it activates after the apex of the jump when the player is holding Jump or when mid-air without any jumps remaining)
- Slide? Its already integrated in base movement when unlocked
- Pogo? Kicker Skeleton soul could be used for this but might be too easy, i need to test how it currently works
- See if I can make the movement feel crispier. Stronger gravity maybe? Change how momentum works?
- Maybe adjust some souls to make them more awesome?
